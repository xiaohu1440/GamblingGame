## 3. 改动内容

**实现（对应卡片 [MUST]）**

- 充能百分比 `progress`（0–100）代替转动次数：每次普通转动 `+100 / max(1, N - D)`，clamp 100；`>= 99.99` 后**下一转**强制落彩蛋，触发后归 0。
- 彩蛋卡不再参与权重抽取（`ChanceWeight = 0`），`GetWeightedRandomIndex()` 显式跳过 0 权重卡（修掉 `randomValue=0` 误命中）。
- 遗物通过 `struct` 事件接入：`EasterEggChargeRuleEvent { SpinsReductionDelta, Enabled }`（减次数 / 关保底），`EasterEggChargeChangedEvent { Progress, Level, Triggered }`（对外广播）。
- 保底关闭时进度条整条隐藏（`SetActive(false)`），重新启用带原百分比显示。
- 减次数**本局生效**，`GamblingGround.Init()` 重置 0 / 0 / true。

## 4. 后续需要增加和注意的点

**待补功能**

- 还没有任何遗物实现 `EasterEggChargeRuleEvent`。要加「减少保底次数 / 关闭保底」的遗物，按 `Docs/Design/彩蛋保底_数值.md` 的契约发事件。
- QA-001 ~ QA-013 尚未逐条做真人 Play 验收，目前只有程序冒烟 + 截图证据。
- 触发瞬间的 0.4s 彩蛋 UI 动画仍按需求「暂时搁置」。

**注意 / 坑**

- `EasterEggChargeRuleEvent.Enabled` 是 `bool`，struct 默认 `false`；遗物只想减次数时必须显式写 `Enabled = true`，否则等于关闭保底。
- 轮盘彩蛋卡**至少 1 张**（当前 2 张：索引 9、21）；保底时等概率随机选一张。0 张才会告警 + 回退权重；**多张是正常配置，不要再按「必须唯一」去删格**（v1.2 修正，旧方案作废）。
- 两张彩蛋必须指向**同一个** `彩蛋.asset`，否则权重/图标会不一致；该资产 `ChanceWeight` 必须 0。
- `GamblingLevel.Rewards` 必须 **≥ 24 条**（`SideCount=7` → `7*4-4`），少一条会导致一格都不建；要减格必须同时改 prefab 的 SideCount 和排布。
- 彩蛋卡 `ChanceWeight` **必须保持 0**；改成非 0 会让彩蛋平时也被自然抽到，破坏保底节奏（QA-004 失效）。
- prefab/资产改动在 Editor **模拟模式**（`SimulateAssetBundles=True`）下即时生效，**不用**重建 AB；
  但 Player 只用真机 AB —— `AgentCI.BuildWindows` 已改为**打包前自动重建 AB**（失败即中止）。
  只有显式用 `AGENT_SKIP_AB=1` 跳过时，才需要自己补一次 `ResKitEditorAPI.BuildAssetBundles()`。
- 模拟模式的代价：看不到「资源没打进 AB / 依赖缺失」这类问题，发布前建议临时切真机模式抽查一次。
- 浮点容差：满格判定用 `>= 99.99f`，不要把 `100/6×6 = 99.999` 当成未满。
- 百分比跨关保留，N 变化只影响后续增量，不重算已有进度（这是设计决定，不是 bug）。

**可调数值与位置**

- `Assets/Resources/Data/EasterEggConfig.asset` → `Required Spins`（默认 4）：保底基础次数 N，执行策划改。
- `CardData/彩蛋.asset` → `Chance Weight`：必须 0，执行策划不得改。
- `GamblingLevel.asset` → `Rewards`：卡牌构成与各卡权重，执行策划改，受上面两条约束。
- 进度条尺寸/颜色/刻线：美术，`UIGamePanel.prefab` 的 `BackGround/EasterEggCharge`。
